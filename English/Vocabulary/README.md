# 英语词汇记忆总览 (English Vocabulary Index)

本目录为英语学科的词汇知识体系，分为两大支柱模块：

---

## 1. [词根体系 (Roots/)](./Roots/README.md)
每个核心词根独立建立文件夹，详细讲解词源、所有派生单词、音标、词性、构词拆解、真题高频考点与常见搭配：

- [`Roots/rupt/`](./Roots/rupt/README.md)：破、断、裂（erupt, interrupt, disrupt, corrupt, bankrupt, abrupt...）
- [`Roots/tract/`](./Roots/tract/README.md)：拉、抽、引（attract, distract, contract, extract, abstract...）
- [`Roots/spect/`](./Roots/spect/README.md)：看、视（inspect, expect, respect, prospect, suspect...）
- [`Roots/dict/`](./Roots/dict/README.md)：说、言（predict, contradict, dictate, verdict, indicate...）
- [`Roots/duc/`](./Roots/duc/README.md)：引、导（produce, reduce, introduce, educate, conduct...）
- [`Roots/vers/`](./Roots/vers/README.md)：转、转向（convert, reverse, diverse, adverse, controversy...）
- [`Roots/port/`](./Roots/port/README.md)：拿、运、运送（import, export, transport, portable, support...）
- [`Roots/press/`](./Roots/press/README.md)：压、按、逼迫（express, impress, depress, suppress, compress...）
- [`Roots/scrib/`](./Roots/scrib/README.md)：写、记（describe, prescribe, subscribe, inscribe, transcript...）
- [`Roots/fac/`](./Roots/fac/README.md)：做、作、造（factory, manufacture, affect, effect, defect...）
- [`Roots/mit/`](./Roots/mit/README.md)：送、发、发射（transmit, admit, permit, emit, submit, dismiss...）
- [`Roots/cur/`](./Roots/cur/README.md)：跑、流动、发生（occur, currency, current, recur, precursor...）
- [`Roots/gen/`](./Roots/gen/README.md)：生、产生、起源（generate, genuine, genius, ingenious...）

## 2. [词缀体系 (Affixes/)](./Affixes/README.md)
词缀独立归档，全面梳理改变词义与词性的规律：

- **[前缀 (Prefixes/)](./Affixes/Prefixes/README.md)**：
  - 否定与相反（un-, in-/im-/il-/ir-, dis-, mis-, non-, anti-, de-...）
  - 空间与方向（ex-, in-/im-/en-, sub-, super-/sur-, inter-, trans-...）
  - 时间与顺序（pre-, post-, fore-, re-...）
  - 数量与程度（mono-, bi-, tri-, multi-, semi-, over-, under-...）
  - 协同与强调（com-/con-, auto-, bene-, mal-...）
- **[后缀 (Suffixes/)](./Affixes/Suffixes/README.md)**：
  - 名词后缀（施动者/人：-er/-or, -ist, -ant/-ent, -ee；抽象概念：-tion, -ment, -ness, -ity, -ship, -dom...）
  - 动词后缀（-ize/-ise, -en, -ify, -ate）
  - 形容词后缀（-able/-ible, -ful, -less, -al, -ic, -ive, -ous, -y...）
  - 副词后缀（-ly, -ward/-wards, -wise）
