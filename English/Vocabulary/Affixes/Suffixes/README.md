# 常见英语后缀全书 (Common English Suffixes)

后缀（Suffix）加在词根或词干之后，主要功能是**决定单词的词性（名词、动词、形容词、副词）**，同时也赋予一定的含义范畴。

---

## 一、名词后缀 (Noun Suffixes)

### 1. 表示“人或物、施动者”的后缀
- **`-er` / `-or`**（做某事的人/工具）：
  - **teacher**（教师）、**worker**（工人）、**printer**（打印机）
  - **actor**（演员）、**conductor**（指挥/导体）、**inspector**（检查员）
- **`-ist`**（……主义者、专业研究者）：
  - **scientist**（科学家）、**economist**（经济学家）、**optimist**（乐观主义者）
- **`-ian` / `-an`**（从事某行业的人、某地人）：
  - **musician**（音乐家）、**physician**（内科医生）、**historian**（历史学家）
- **`-ant` / `-ent`**（……的人、剂）：
  - **assistant**（助手）、**consultant**（顾问）、**pollutant**（污染物）
  - **student**（学生）、**resident**（居民）、**agent**（代理人）
- **`-ee`**（动作的承受者、被动者）：
  - **employee**（雇员）、**interviewee**（被面试者）、**trainee**（受训者）

### 2. 表示“状态、性质、抽象概念”的后缀
- **`-tion` / `-sion` / `-ation`**（动作、过程、结果）：
  - **action**（行动）、**creation**（创造）、**decision**（决定）、**expansion**（扩张）
- **`-ment`**（行为、状态、结果）：
  - **development**（发展）、**government**（政府）、**movement**（运动）、**punishment**（惩罚）
- **`-ness`**（性质、状态，多由形容词转化）：
  - **happiness**（幸福）、**kindness**（仁慈）、**darkness**（黑暗）、**awareness**（意识）
- **`-ity` / `-ty`**（性质、状态、程度）：
  - **activity**（活动）、**reality**（现实）、**creativity**（创造力）、**security**（安全）
- **`-ance` / `-ence`**（性质、状况、行为）：
  - **importance**（重要性）、**performance**（表现）、**confidence**（信心）、**difference**（差异）
- **`-ship`**（关系、身份、技能、状态）：
  - **friendship**（友谊）、**leadership**（领导力）、**scholarship**（奖学金/学问）
- **`-hood`**（时期、身份、群体）：
  - **childhood**（童年）、**neighborhood**（邻里、街区）、**likelihood**（可能性）
- **`-dom`**（领域、状态、管辖范围）：
  - **freedom**（自由）、**wisdom**（智慧）、**kingdom**（王国）
- **`-ism`**（主义、学说、特征现象）：
  - **realism**（现实主义）、**optimism**（乐观主义）、**criticism**（批评）

---

## 二、动词后缀 (Verb Suffixes)

动词后缀主要表示“使成为……”、“化”、“做……”。

- **`-ize` / `-ise`**（使……化）：
  - **realize**（意识到、实现）、**modernize**（使现代化）、**standardize**（标准化）、**criticize**（批评）
- **`-en`**（使变成、变得）：
  - **widen**（拓宽）、**strengthen**（加强）、**shorten**（缩短）、**quicken**（加快）
- **`-ify` / `-fy`**（使成……、使……化）：
  - **clarify**（澄清）、**simplify**（简化）、**identify**（识别、认同）、**purify**（净化）
- **`-ate`**（使……、做、产生）：
  - **activate**（激活）、**create**（创造）、**motivate**（激发）、**differentiate**（区分）

---

## 三、形容词后缀 (Adjective Suffixes)

### 1. 表示“有……属性、具备……能力”
- **`-able` / `-ible`**（能……的、易……的、值得……的）：
  - **readable**（易读的）、**reliable**（可信赖的）、**sustainable**（可持续的）
  - **visible**（可见的）、**flexible**（灵活的）、**feasible**（可行的）
- **`-ful`**（充满……的、具有……性质的）：
  - **helpful**（有帮助的）、**careful**（小心的）、**successful**（成功的）、**meaningful**（有意义的）
- **`-less`**（无……的、没有……的）：
  - **hopeless**（绝望的）、**careless**（粗心的）、**endless**（无休止的）、**wireless**（无线的）

### 2. 表示“与……有关的、具有……特征的”
- **`-al` / `-ial`**：
  - **national**（国家的）、**traditional**（传统的）、**potential**（潜在的）、**essential**（本质的）
- **`-ic` / `-ical`**：
  - **economic**（经济上的）、**economical**（节约的）、**historic**（历史著名的）、**historical**（历史上的）
- **`-ive`**（有……倾向的、产生……作用的）：
  - **active**（活跃的）、**creative**（有创造力的）、**comprehensive**（综合全面的）、**decisive**（决定性的）
- **`-ous` / `-ious`**（充满……的、具有……特性的）：
  - **famous**（著名的）、**dangerous**（危险的）、**continuous**（连续的）、**curious**（好奇的）
- **`-ish`**（带有……性质的、稍显……的）：
  - **childish**（幼稚的）、**foolish**（愚蠢的）、**reddish**（略带红色的）
- **`-y`**（充满……的、多……的）：
  - **healthy**（健康的）、**wealthy**（富有的）、**sunny**（阳光充足的）、**risky**（有风险的）

---

## 四、副词后缀 (Adverb Suffixes)

- **`-ly`**（……地，通常由形容词派生）：
  - **quickly**（迅速地）、**effectively**（有效地）、**inevitably**（不可避免地）
  - *注意特例*：有些以 -ly 结尾是形容词，如 **friendly**（友好的）、**likely**（可能的）、**lovely**（可爱的）。
- **`-ward` / `-wards`**（朝……方向）：
  - **forward**（向前）、**backward**（向后）、**inward**（向内）、**upward**（向上）
- **`-wise`**（在……方面、按……方式）：
  - **otherwise**（否则、不同地）、**clockwise**（顺时针地）、**crosswise**（交叉地）
