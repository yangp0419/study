# 常见英语前缀全书 (Common English Prefixes)

前缀（Prefix）加在词根之前，主要用来**改变或限制词根的意义（方向、否定、数量、时间等）**，通常不改变词性。

---

## 一、否定与相反前缀 (Negative / Opposite Prefixes)

### 1. `un-`（不、非；相反动作）
- **unable** *adj.* 不能的、无能力的
- **unemployment** *n.* 失业
- **unlock** *v.* 开锁、解开（与 lock 相反）
- **unfold** *v.* 展开、呈现

### 2. `in-` / `im-` / `il-` / `ir-`（不、非 —— 依后接首辅音同化）
- **in-**：**inactive**（不活跃的）、**inseparable**（不可分离的）、**inevitable**（不可避免的）
- **im-**（用于 b, m, p 前）：**impossible**（不可能的）、**immoral**（不道德的）、**impatient**（不耐烦的）
- **il-**（用于 l 前）：**illegal**（非法的）、**illogical**（不合逻辑的）、**illiterate**（文盲的）
- **ir-**（用于 r 前）：**irregular**（不规则的）、**irresponsible**（不负责任的）、**irresistible**（不可抗拒的）

### 3. `dis-`（不、相反、分离剥夺）
- **disagree** *v.* 不同意
- **disadvantage** *n.* 劣势、缺点
- **disable** *v.* 使残废、使丧失能力
- **disappear** *v.* 消失

### 4. `mis-`（错误、坏、不当）
- **misunderstand** *v.* 误解
- **misleading** *adj.* 误导的
- **misconduct** *n.* 不当行为、渎职
- **misfortune** *n.* 不幸、灾祸

### 5. `non-`（非、不 —— 中性客观否定）
- **nonsense** *n.* 废话、胡说
- **non-profit** *adj.* 非营利的
- **non-renewable** *adj.* 不可再生的

### 6. `anti-` / `contra-` / `counter-`（反、对抗、逆）
- **anti-**：**antibiotic**（抗生素）、**anticancer**（抗癌的）、**antithesis**（对立面）
- **contra-**：**contradict**（反驳、矛盾）、**contrast**（对比、对照）
- **counter-**：**counterpart**（对应的人或物）、**counterproductive**（适得其反的）、**counterattack**（反击）

### 7. `de-`（向下、去除、否定、逆转）
- **decrease** *v.* 减少
- **degrade** *v.* 降级、退化
- **decelerate** *v.* 减速
- **deforestation** *n.* 滥伐森林

---

## 二、空间与方向前缀 (Spatial / Directional Prefixes)

### 1. `ex-` / `e-` / `ef-`（向外、出）
- **export** *v.* 出口
- **exclude** *v.* 排除在外
- **emerge** *v.* 浮现、显露
- **efflux** *n.* 流出

### 2. `in-` / `im-` / `en-` / `em-`（向内、进入；使成为）
- **import** *v.* 进口、输入
- **invade** *v.* 入侵、侵略
- **enable** *v.* 使能够
- **enrich** *v.* 使丰富
- **empower** *v.* 授权、赋予力量

### 3. `sub-` / `suc-` / `suf-` / `sup-` / `sus-`（在……之下、次级、隐秘）
- **subway** *n.* 地铁
- **submarine** *n.* 潜水艇
- **subconscious** *adj.* 潜意识的
- **suppress** *v.* 镇压、抑制（sub + press）
- **suspend** *v.* 悬挂、暂停（sub + pend）

### 4. `super-` / `sur-`（在……之上、超过、超级）
- **supermarket** *n.* 超级市场
- **superior** *adj.* 上级的、优秀的
- **supervise** *v.* 监督、指导（从高处看）
- **surface** *n.* 表面
- **surplus** *n.* 过剩、盈余

### 5. `inter-`（在……之间、相互）
- **international** *adj.* 国际的
- **interact** *v.* 互动、相互作用
- **internet** *n.* 互联网
- **intervene** *v.* 干涉、介入

### 6. `trans-`（横过、贯通、转换）
- **transport** *v.* 运输
- **translate** *v.* 翻译
- **transform** *v.* 转换、转变
- **transparent** *adj.* 透明的、显然的

### 7. `tele-`（远距离）
- **telephone** *n.* 电话
- **telescope** *n.* 望远镜
- **telecommunication** *n.* 远程通信

### 8. `circum-`（环绕、周围）
- **circumstance** *n.* 环境、情况
- **circumnavigate** *v.* 环球航行
- **circumvent** *v.* 规避、绕行

### 9. `intro-` / `intra-`（向内、在内）
- **introduce** *v.* 引入、介绍（向内引导）
- **introspective** *adj.* 内省的、反思的
- **intranet** *n.* 内部局域网

---

## 三、时间与顺序前缀 (Temporal / Order Prefixes)

### 1. `pre-`（在……之前、预先）
- **predict** *v.* 预言、预测
- **prepare** *v.* 准备
- **precaution** *n.* 预防措施
- **precedent** *n.* 先例

### 2. `post-`（在……之后）
- **postpone** *v.* 推迟、延期
- **postgraduate** *n.* 研究生
- **postwar** *adj.* 战后的

### 3. `fore-`（前、先）
- **forecast** *v./n.* 预测、预报
- **forehead** *n.* 前额
- **foresee** *v.* 预见

### 4. `re-`（再次、重新；往回、退）
- **review** *v./n.* 复习、审查
- **rebuild** *v.* 重建
- **recall** *v.* 回忆起、召回
- **return** *v.* 返回

---

## 四、数量与程度前缀 (Quantity & Degree Prefixes)

### 1. 数量系列
- **mono-** / **uni-**（单一、独个）：
  - **monopoly** *n.* 垄断
  - **monologue** *n.* 独白
  - **unify** *v.* 统一
  - **unique** *adj.* 独一无二的
- **bi-** / **di-**（二、双）：
  - **bilingual** *adj.* 双语的
  - **bicycle** *n.* 自行车
  - **dilemma** *n.* 两难境地
- **tri-**（三）：
  - **triangle** *n.* 三角形
  - **triple** *adj.* 三倍的
- **multi-** / **poly-**（多）：
  - **multiple** *adj.* 多样的、多重的
  - **multimedia** *n.* 多媒体
  - **polygon** *n.* 多边形
- **semi-** / **hemi-**（半）：
  - **semiconductor** *n.* 半导体
  - **hemisphere** *n.* 半球

### 2. 程度系列
- **over-**（过度、在……上方、翻转）：
  - **overestimate** *v.* 高估
  - **overcome** *v.* 克服
  - **overlook** *v.* 俯瞰；忽视
- **under-**（不足、在……下方）：
  - **underestimate** *v.* 低估
  - **underdeveloped** *adj.* 不发达的
  - **underline** *v.* 在……下划线；强调
- **hyper-**（过度、超）：
  - **hypertension** *n.* 高血压
  - **hyperlink** *n.* 超链接
- **out-**（超越、胜过）：
  - **outnumber** *v.* 数量多于
  - **outperform** *v.* 表现优于

---

## 五、强调与协同前缀 (Intensive & Co- prefixes)

### 1. `com-` / `con-` / `col-` / `cor-` / `co-`（共同、一起；加强语气）
- **co-**：**cooperate**（合作）、**coexist**（共存）
- **com-**（b, p, m 前）：**combine**（结合）、**compact**（紧凑的）、**compress**（压缩）
- **con-**：**connect**（连接）、**construct**（构建）、**concur**（同时发生、同意）
- **col-**（l 前）：**collaborate**（协作）、**collect**（收集）
- **cor-**（r 前）：**correct**（纠正）、**correlate**（相互关联）

### 3. `ad-`（向、朝、靠近、加强 —— 依后接辅音同化为 `ac-` / `af-` / `ag-` / `al-` / `an-` / `ap-` / `ar-` / `as-` / `at-`）
- **ad-**：**adapt**（适应）、**adopt**（采纳）、**admit**（承认）
- **at-**（t 前）：**attach** *v.* 附上、系上（ad + *steg- 靠近并固定）、**attract** *v.* 吸引（ad + tract 朝自己拉）
- **ap-**（p 前）：**apply**（应用、申请）、**appoint**（任命）
- **ac-**（c/k 前）：**accelerate**（加速）、**accumulate**（积累）

### 4. `auto-`（自己、自动）
- **automatic** *adj.* 自动的
- **autonomy** *n.* 自治、自主
- **autobiography** *n.* 自传

### 3. `bene-`（好、善） / `mal-`（坏、恶）
- **benefit** *n.* 益处、恩惠
- **beneficial** *adj.* 有益的
- **malfunction** *n./v.* 故障、失灵
- **malnutrition** *n.* 营养不良
