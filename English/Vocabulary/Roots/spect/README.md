# 词根专练：-spect- / -spic-（Look, See 看、视）

> **词根来源**：拉丁语 *specere*（过去分词 *spectus*），意为 **"look, see"（看、注视）**。

---

## 核心单词与精讲

### 1. inspect
- **音标**：/ɪnˈspekt/
- **词性**：*v.*
- **拆解**：`in-`（into 深入往里）+ `spect`（看） $\to$ 往里面仔细看
- **释义**：检查、视察、审视
- **常用搭配**：*inspect the factory*（视察工厂）、*inspect for defects*（检查瑕疵）
- **派生词**：**inspector** *n.* 检查员、巡官；**inspection** *n.* 视察、检查

### 2. expect
- **音标**：/ɪkˈspekt/
- **词性**：*v.*
- **拆解**：`ex-`（向外）+ `spect`（看、张望） $\to$ 伸着脖子向外望
- **释义**：期待、预期、期望
- **常用搭配**：*expect high standards*（期望高标准）、*beyond expectations*（超乎预期）
- **派生词**：**expectation** *n.* 期望、期待；**unexpected** *adj.* 意料之外的

### 3. respect
- **音标**：/rɪˈspekt/
- **词性**：*v. / n.*
- **拆解**：`re-`（again 反复回头）+ `spect`（看） $\to$ 敬佩某人因此不住回头瞻仰
- **释义**：*v.* 尊敬、尊重；遵守；*n.* 敬重；方面、着眼点
- **常用搭配**：*in this respect*（在这一方面）、*respect human rights*（尊重人权）
- **派生词**：**respectable** *adj.* 体面的、值得尊敬的；**respectful** *adj.* 恭敬的；**respective** *adj.* 各自的

### 4. prospect
- **音标**：/ˈprɒspekt/
- **词性**：*n. / v.*
- **拆解**：`pro-`（forward 向前）+ `spect`（看） $\to$ 向前方看去的景象
- **释义**：*n.* 前景、前途、期望；*v.* 勘探（矿藏）
- **常用搭配**：*job prospects*（就业前景）、*prospect for gold*（淘金勘探）
- **派生词**：**prospective** *adj.* 未来的、预期的

### 5. suspect
- **音标**：/səˈspekt/ (v.) /ˈsʌspekt/ (n.)
- **词性**：*v. / n. / adj.*
- **拆解**：`sub-`（under 在底下）+ `spect`（看） $\to$ 在底下偷偷斜眼打量
- **释义**：*v.* 怀疑、不信任；*n.* 嫌疑人；*adj.* 可疑的
- **常用搭配**：*suspect foul play*（怀疑有诈/谋杀）、*prime suspect*（主要嫌疑人）
- **派生词**：**suspicion** *n.* 怀疑；**suspicious** *adj.* 可疑的

### 6. retrospect
- **音标**：/ˈretrəspekt/
- **词性**：*n. / v.*
- **拆解**：`retro-`（backward 向后）+ `spect`（看） $\to$ 向身后往事回望
- **释义**：*n.* 回顾、追溯
- **常用搭配**：*in retrospect*（回想起来、事后看来）
- **派生词**：**retrospective** *adj.* 回顾的、追溯的

### 7. conspicuous
- **音标**：/kənˈspɪkjuəs/
- **词性**：*adj.*
- **拆解**：`con-`（加强语气）+ `spic`（看）+ `-uous`（易于……的） $\to$ 一眼就能全看见的
- **释义**：显眼的、引人注目的
- **常用搭配**：*conspicuous consumption*（炫耀性消费）
