# 词根专练：-cur- / -curs-（Run, Happen 跑、流动、发生）

> **词根来源**：拉丁语 *currere*（过去分词 *cursus*），意为 **"run, move quickly"（跑、流动、发生）**。

---

## 核心单词与精讲

### 1. occur
- **音标**：/əˈkɜːr/
- **拆解**：`ob-`（against/towards 迎面而来）+ `cur`（跑来） $\to$ 迎面跑向视线
- **释义**：*v.* 发生、出现；被想到
- **常用搭配**：*it occurs to me that...*（我突然想到……）
- **派生词**：**occurrence** *n.* 发生的事、事件

### 2. current & currency
- **current**：*adj.* 当前的、流通的；*n.* 水流、气流、电流、思潮
- **currency**：`cur` + `-ency` $\to$ 在市场上四处跑动流转的等价物 $\to$ *n.* 货币、通货；流行、流通

### 3. recur
- **音标**：/rɪˈkɜːr/
- **拆解**：`re-`（again 再次）+ `cur`（跑出来） $\to$ 再次跑出来
- **释义**：*v.* 重现、反复发生、复发
- **派生词**：**recurrent** *adj.* 反复出现的；**recurrence** *n.* 复发、重现

### 4. precursor
- **音标**：/priːˈkɜːsər/
- **拆解**：`pre-`（before 前面）+ `curs`（跑）+ `-or`（者） $\to$ 跑在队伍前列的先驱
- **释义**：*n.* 先驱、前兆、雏形

### 5. excursion
- **音标**：/ɪkˈskɜːʃn/
- **拆解**：`ex-`（out 向外）+ `curs`（跑）+ `-ion` $\to$ 到外面散步跑跑
- **释义**：*n.* 远足、短途旅行、离题
