# 词根专练：-port-（Carry 拿、运、运送）

> **词根来源**：拉丁语 *portare*，意为 **"carry, bear"（搬运、运送、携带）**。

---

## 核心单词与精讲

### 1. import & export
- **import**：`im-`（in 入）+ `port` $\to$ *v./n.* 进口、输入；重要性
- **export**：`ex-`（out 出）+ `port` $\to$ *v./n.* 出口、输出

### 2. transport
- **音标**：/trænˈspɔːt/ (v.) /ˈtrænspɔːt/ (n.)
- **拆解**：`trans-`（across 跨越地域）+ `port`（运） $\to$ 跨区域运送
- **释义**：*v./n.* 运输、运送；交通工具
- **派生词**：**transportation** *n.* 运输系统、交通运输

### 3. support
- **音标**：/səˈpɔːt/
- **拆解**：`sub-`（under 在下面）+ `port`（托起扛住） $\to$ 从底下托举支撑
- **释义**：*v./n.* 支持、拥护、支撑、资助
- **常用搭配**：*financial support*（经济援助）、*supportive* *adj.* 鼎力支持的

### 4. portable
- **音标**：/ˈpɔːtəbl/
- **拆解**：`port`（运送携带）+ `-able`（易于……的）
- **释义**：*adj.* 便携的、手提式的、轻便的
- **常用搭配**：*portable computer / device*（便携式电脑/便携设备）

### 5. report
- **音标**：/rɪˈpɔːt/
- **拆解**：`re-`（back 带回）+ `port`（运） $\to$ 把前线侦查的消息带回来呈递
- **释义**：*v./n.* 汇报、报道、报告
- **派生词**：**reporter** *n.* 记者

### 6. deport
- **音标**：/dɪˈpɔːt/
- **拆解**：`de-`（away 移走）+ `port`（运） $\to$ 押运离开本国
- **释义**：*v.* 把……驱逐出境
- **派生词**：**deportation** *n.* 驱逐出境
