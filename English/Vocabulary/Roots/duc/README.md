# 词根专练：-duc- / -duct-（Lead 引、导）

> **词根来源**：拉丁语 *ducere*（过去分词 *ductus*），意为 **"lead, guide"（引领、传导）**。

---

## 核心单词与精讲

### 1. produce
- **音标**：/prəˈdjuːs/ (v.) /ˈprɒdjuːs/ (n.)
- **词性**：*v. / n.*
- **拆解**：`pro-`（forward 向前）+ `duce`（引） $\to$ 引导出来展示于世
- **释义**：*v.* 生产、制造、产生；*n.* 农产品
- **派生词**：**product** *n.* 产品；**production** *n.* 生产；**productive** *adj.* 多产的高效的

### 2. reduce
- **音标**：/rɪˈdjuːs/
- **词性**：*v.*
- **拆解**：`re-`（back 往回）+ `duce`（引、缩） $\to$ 往回引导收缩
- **释义**：减少、降低、简化
- **常用搭配**：*reduce costs*（削减成本）、*reduce pollution*（减少污染）
- **派生词**：**reduction** *n.* 减少、降低

### 3. introduce
- **音标**：/ˌɪntrəˈdjuːs/
- **词性**：*v.*
- **拆解**：`intro-`（inward 向内）+ `duce`（引） $\to$ 引进门
- **释义**：介绍、引进、推行
- **派生词**：**introduction** *n.* 介绍、导言、引进

### 4. educate
- **音标**：/ˈedʒukeɪt/
- **词性**：*v.*
- **拆解**：`e-`（out 向外）+ `duc`（引导）+ `-ate` $\to$ 把学生的内在潜能引导启发出来
- **释义**：教育、教导、培养
- **派生词**：**education** *n.* 教育；**educational** *adj.* 有教育意义的

### 5. conduct
- **音标**：/kənˈdʌkt/ (v.) /ˈkɒndʌkt/ (n.)
- **词性**：*v. / n.*
- **拆解**：`con-`（共同、一起）+ `duct`（引、导） $\to$ 带领全员一同进行
- **释义**：*v.* 组织、实施、指挥（乐队）、传导（热/电）；*n.* 行为、举止
- **常用搭配**：*conduct an experiment / survey*（进行实验/调查）
- **派生词**：**conductor** *n.* 指挥家、导体、售票员

### 6. deduce
- **音标**：/dɪˈdjuːs/
- **词性**：*v.*
- **拆解**：`de-`（down 从既定事实向下）+ `duce`（引出） $\to$ 从大前提出发演绎
- **释义**：推论、演绎、推断
- **派生词**：**deduction** *n.* 推论、演绎、扣除
