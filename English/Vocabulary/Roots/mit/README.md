# 词根专练：-mit- / -miss-（Send, Cast 送、发、发射）

> **词根来源**：拉丁语 *mittere*（过去分词 *missus*），意为 **"send, cast"（派遣、发送、投掷、放行）**。

---

## 核心单词与精讲

### 1. transmit
- **音标**：/trænzˈmɪt/
- **拆解**：`trans-`（across 跨越、传输）+ `mit`（送） $\to$ 跨距离传递
- **释义**：*v.* 传输、传播（疾病/信号）、播送
- **派生词**：**transmission** *n.* 传播、发射、齿轮变速箱

### 2. admit
- **音标**：/ədˈmɪt/
- **拆解**：`ad-`（to 朝向）+ `mit`（送进） $\to$ 准许跨进门内
- **释义**：*v.* 承认、供认；准许……进入、招收
- **派生词**：**admission** *n.* 准许进入、门票、入场费；承认

### 3. permit
- **音标**：/pəˈmɪt/ (v.) /ˈpɜːmɪt/ (n.)
- **拆解**：`per-`（through 穿透通过）+ `mit`（放行） $\to$ 让人通过
- **释义**：*v.* 允许、许可；*n.* 许可证、执照
- **派生词**：**permission** *n.* 许可、准许；**permissive** *adj.* 宽容放任的

### 4. emit
- **音标**：/iˈmɪt/
- **拆解**：`e-`（out 向外）+ `mit`（发射） $\to$ 往外发射释放
- **释义**：*v.* 发出、排放、射出（光、热、气体、声音）
- **常用搭配**：*emit greenhouse gases*（排放温室气体）
- **派生词**：**emission** *n.* 排放、辐射物

### 5. submit
- **音标**：/səbˈmɪt/
- **拆解**：`sub-`（under 在……之下）+ `mit`（送递） $\to$ 恭敬呈送到底下；把自己放在对方统治下
- **释义**：*v.* 提交、呈递；屈服、服从
- **派生词**：**submission** *n.* 提交、服从；**submissive** *adj.* 顺从的

### 6. dismiss
- **音标**：/dɪsˈmɪs/
- **拆解**：`dis-`（away 散开）+ `miss`（送走） $\to$ 打发打发走人
- **释义**：*v.* 解雇、开除；驳回、对……不屑一顾；解散
- **派生词**：**dismissal** *n.* 解雇、驳回
