# 词根专练：-press-（Press 压、挤、逼迫）

> **词根来源**：拉丁语 *premere*（过去分词 *pressus*），意为 **"press, squeeze"（按压、挤压、迫近）**。

---

## 核心单词与精讲

### 1. express
- **音标**：/ɪkˈspres/
- **拆解**：`ex-`（out 向外）+ `press`（挤压） $\to$ 把心底的所思所想榨压出来
- **释义**：*v.* 表达、陈述；*adj.* 特快的、快递的；*n.* 快车、快递
- **常用搭配**：*express one's feelings*（表达感情）、*express delivery*（快递）
- **派生词**：**expression** *n.* 表达、表情、短语；**expressive** *adj.* 富于表现力的

### 2. impress
- **音标**：/ɪmˈpres/
- **拆解**：`im-`（in 向内）+ `press`（压印） $\to$ 像图章一样深刻压印在心脑中
- **释义**：*v.* 给……留下深刻印象、使钦佩
- **常用搭配**：*impress someone with knowledge*（以学识令人佩服）
- **派生词**：**impression** *n.* 印象；**impressive** *adj.* 令人赞叹的、令人难忘的

### 3. depress
- **音标**：/dɪˈpres/
- **拆解**：`de-`（down 向下）+ `press`（压） $\to$ 心情或经济被往下拉压
- **释义**：*v.* 使抑郁、使沮丧；使萧条、不景气；按压
- **派生词**：**depression** *n.* 抑郁症、大萧条、沮丧；**depressive** *adj.* 引起抑郁的

### 4. suppress
- **音标**：/səˈpres/
- **拆解**：`sub-`（under 在底下）+ `press`（压） $\to$ 往下强力压制不让露头
- **释义**：*v.* 镇压、平息；抑制（感情/欲望）；封锁（真相）
- **常用搭配**：*suppress an uprising*（镇压起义）、*suppress one's anger*（抑制怒火）

### 5. compress
- **音标**：/kəmˈpres/
- **拆解**：`com-`（together 在一起）+ `press`（压） $\to$ 四周往中间聚压
- **释义**：*v.* 压缩、浓缩
- **常用搭配**：*compressed air*（压缩空气）、*data compression*（数据压缩）

### 6. oppress
- **音标**：/əˈpres/
- **拆解**：`ob-`（against 对着）+ `press`（压） $\to$ 压迫在头上
- **释义**：*v.* 压迫、苛待、使压抑
- **派生词**：**oppression** *n.* 压迫；**oppressive** *adj.* 压迫残酷的、闷热压抑的
