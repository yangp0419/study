# 词根专练：-fac- / -fic- / -fect-（Make, Do 做、作、造）

> **词根来源**：拉丁语 *facere*（过去分词 *factus*），意为 **"make, do"（制造、行动、起作用）**。

---

## 核心单词与精讲

### 1. factory & manufacture
- **factory**：`fac` + `-ory`（场所） $\to$ 制造东西的地方（工厂）
- **manufacture**：`manu`（手） + `fact` + `-ure` $\to$ *v./n.*（手工或机器）大批量制造

### 2. affect & effect (考研高频辨析)
- **affect**：`ad-`（to 趋向）+ `fect`（起作用） $\to$ **主要是动词**，表示“对……产生影响、波及；感动”
  - *e.g.* Smoking affects your health.
  - 派生词：**affection** *n.* 喜爱、钟爱
- **effect**：`ex-`（out 做出来的效果）+ `fect` $\to$ **主要是名词**，表示“效果、影响、结果”
  - *e.g.* The new law takes effect next month.
  - 派生词：**effective** *adj.* 有效的；**efficient** *adj.* 高效的

### 3. defect
- **音标**：/ˈdiːfekt/ (n.) /dɪˈfekt/ (v.)
- **拆解**：`de-`（away 偏离）+ `fect`（制作） $\to$ 制作得不够健全
- **释义**：*n.* 缺点、缺陷、瑕疵；*v.* 背叛、叛逃
- **派生词**：**defective** *adj.* 有缺陷的

### 4. sufficient & deficient
- **sufficient**：`sub-`（under 底端做起）+ `fic` + `-ient` $\to$ *adj.* 充分的、足够的
- **deficient**：`de-`（向下/缺乏）+ `fic` + `-ient` $\to$ *adj.* 缺乏的、不足的
  - 派生词：**deficit** *n.* 赤字、亏损、不足

### 5. beneficial
- **音标**：/ˌbenɪˈfɪʃl/
- **拆解**：`bene`（good 好）+ `fic`（做）+ `-ial` $\to$ 做好事的
- **释义**：*adj.* 有益的、有利的
- **派生词**：**benefit** *n./v.* 益处、得益于
