# 词根专练：-dict- / -dic-（Say, Speak 说、言）

> **词根来源**：拉丁语 *dicere*（过去分词 *dictus*），意为 **"say, speak, declare"（说、讲、宣布）**。

---

## 核心单词与精讲

### 1. predict
- **音标**：/prɪˈdɪkt/
- **词性**：*v.*
- **拆解**：`pre-`（before 事先）+ `dict`（说） $\to$ 事情发生之前先说出来
- **释义**：预言、预测、预报
- **常用搭配**：*predict the future*（预测未来）、*hard to predict*（难以预料）
- **派生词**：**prediction** *n.* 预言、预测；**predictable** *adj.* 可预测的

### 2. contradict
- **音标**：/ˌkɒntrəˈdɪkt/
- **词性**：*v.*
- **拆解**：`contra-`（against 相反、对着）+ `dict`（说） $\to$ 唱反调、对着说
- **释义**：反驳、驳斥；与……相矛盾、不一致
- **常用搭配**：*contradict oneself*（自相矛盾）、*facts contradict theories*（事实与理论相悖）
- **派生词**：**contradiction** *n.* 矛盾、反驳；**contradictory** *adj.* 矛盾的

### 3. dictate
- **音标**：/dɪkˈteɪt/
- **词性**：*v. / n.*
- **拆解**：`dict`（说）+ `-ate`（动词后缀） $\to$ 居高临下地说、命令
- **释义**：*v.* 口授、听写；命令、支配、决定；*n.* 命令、原则
- **常用搭配**：*dictate letters*（口述信件）、*dictated by circumstances*（由环境决定）
- **派生词**：**dictator** *n.* 独裁者；**dictatorship** *n.* 专政、独裁统治

### 4. verdict
- **音标**：/ˈvɜːdɪkt/
- **词性**：*n.*
- **拆解**：`ver`（true 真实）+ `dict`（说） $\to$ 陪审团说出真话
- **释义**：（法庭陪审团的）裁决、裁定；定论、评判
- **常用搭配**：*reach / deliver a verdict*（做出裁决）

### 5. indicate
- **音标**：/ˈɪndɪkeɪt/
- **词性**：*v.*
- **拆解**：`in-`（towards 指向）+ `dic`（说、宣布）+ `-ate` $\to$ 指着说清楚
- **释义**：表明、暗示、象征、指示
- **常用搭配**：*research indicates that...*（研究表明……）
- **派生词**：**indication** *n.* 指示、迹象；**indicator** *n.* 指标、标志

### 6. addict
- **音标**：/ˈædɪkt/ (n.) /əˈdɪkt/ (v.)
- **词性**：*n. / v.*
- **拆解**：`ad-`（to 趋向）+ `dict`（宣告判给） $\to$ 古罗马把人判给债主为奴，引申为沉沦
- **释义**：*n.* 吸毒成瘾者、对……入迷的人；*v.* 使沉溺、使成瘾
- **常用搭配**：*be addicted to games / drugs*（沉迷于游戏/毒品）
- **派生词**：**addiction** *n.* 瘾、沉迷；**addictive** *adj.* 使人上瘾的
