# 词根专练：-scrib- / -script-（Write 写、记）

> **词根来源**：拉丁语 *scribere*（过去分词 *scriptus*），意为 **"write, record"（书写、记录）**。

---

## 核心单词与精讲

### 1. describe
- **音标**：/dɪˈskraɪb/
- **拆解**：`de-`（down 记录下来）+ `scribe`（写） $\to$ 笔录所见所闻
- **释义**：*v.* 描述、描绘、描写
- **派生词**：**description** *n.* 描述、描写；**descriptive** *adj.* 描述性的

### 2. prescribe
- **音标**：/prɪˈskraɪb/
- **拆解**：`pre-`（before 预先）+ `scribe`（写） $\to$ 医生/法官预先写好配方与规则
- **释义**：*v.* 开处方、开药；规定、指示
- **常用搭配**：*prescribe antibiotics*（开抗生素）
- **派生词**：**prescription** *n.* 药方、处方；规定；**prescriptive** *adj.* 规范性的

### 3. subscribe
- **音标**：/səbˈskraɪb/
- **拆解**：`sub-`（under 在底部）+ `scribe`（写） $\to$ 在协议合同最底部签名确认
- **释义**：*v.* 订阅（报刊/频道）；赞同、同意（观念）；定期捐助
- **常用搭配**：*subscribe to a journal / channel*（订阅期刊/频道）、*subscribe to this view*（赞同这种观点）
- **派生词**：**subscription** *n.* 订阅费、订阅

### 4. inscribe
- **音标**：/ɪnˈskraɪb/
- **拆解**：`in-`（into 刻入）+ `scribe`（写） $\to$ 题刻在石碑/器物表面
- **释义**：*v.* 题写、题献、铭刻
- **派生词**：**inscription** *n.* 题词、铭文、碑文

### 5. manuscript
- **音标**：/ˈmænjuskrɪpt/
- **拆解**：`manu`（hand 手）+ `script`（写、稿） $\to$ 亲手书写的稿件
- **释义**：*n.* 手稿、原稿、底稿

### 6. transcript
- **音标**：/ˈtrænskrɪpt/
- **拆解**：`trans-`（across 转移转换）+ `script`（写出） $\to$ 跨媒介转录下来的文本
- **释义**：*n.* 成绩单、转录文本、会议记录
