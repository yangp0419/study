# 词根专练：-vers- / -vert-（Turn 转、转向）

> **词根来源**：拉丁语 *vertere*（过去分词 *versus*），意为 **"turn"（旋转、转向、翻转）**。

---

## 核心单词与精讲

### 1. convert
- **音标**：/kənˈvɜːt/ (v.) /ˈkɒnvɜːt/ (n.)
- **拆解**：`con-`（完全、彻底）+ `vert`（转） $\to$ 彻底转变
- **释义**：*v.* 改变（形式/信仰/用途）、兑换（货币）；*n.* 皈依者
- **常用搭配**：*convert solar energy into electricity*（将太阳能转化为电能）
- **派生词**：**conversion** *n.* 转变、转换

### 2. reverse
- **音标**：/rɪˈvɜːs/
- **拆解**：`re-`（back 往回）+ `vers`（转） $\to$ 转回反向
- **释义**：*v.* 彻底改变、倒退、反转；*adj.* 相反的、反面的；*n.* 逆境、背面
- **常用搭配**：*reverse a decision / trend*（逆转决定/趋势）
- **派生词**：**reversible** *adj.* 可逆的；**irreversible** *adj.* 不可逆的

### 3. diverse
- **音标**：/daɪˈvɜːs/
- **拆解**：`di-`（apart 转向不同方向）+ `vers`（转） $\to$ 各转各的、形形色色
- **释义**：*adj.* 不同的、多种多样的
- **常用搭配**：*culturally diverse*（文化多元的）
- **派生词**：**diversity** *n.* 多样性；**diversify** *v.* 使多样化、分散投资

### 4. adverse
- **音标**：/ˈædvɜːs/
- **拆解**：`ad-`（to 冲着迎面而来）+ `vers`（转） $\to$ 逆面转过来的风阻
- **释义**：*adj.* 不利的、有害的、逆向的
- **常用搭配**：*adverse effects / conditions*（不良影响/恶劣环境）
- **派生词**：**adversity** *n.* 逆境、苦难；**adversary** *n.* 对手、敌手

### 5. subvert
- **音标**：/səbˈvɜːt/
- **拆解**：`sub-`（under 底座）+ `vert`（翻转） $\to$ 从地基底部把大厦掀翻
- **释义**：*v.* 颠覆、推翻（政权、既定观念）
- **派生词**：**subversion** *n.* 颠覆；**subversive** *adj.* 颠覆性的

### 6. controversy
- **音标**：/ˈkɒntrəvɜːsi/
- **拆解**：`contro-`（against 相对立）+ `vers`（转）+ `-y` $\to$ 双方反向转动争辩
- **释义**：*n.* 争论、争议
- **常用搭配**：*arouse / cause controversy*（引起争议）
- **派生词**：**controversial** *adj.* 有争议的
