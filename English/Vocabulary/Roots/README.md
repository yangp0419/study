| **-spect- / -spic-** | 看、视 | look, see | [Roots/spect/](./spect/README.md) |
| **-dict- / -dic-** | 说、言 | say, speak | [Roots/dict/](./dict/README.md) |

| **-press-** | 压、按、逼迫 | press, squeeze | [Roots/press/](./press/README.md) |
